## The main difference is **how you connect the action to the present**.

 ### 1\. “I did something” — Simple Past

 Use **“I did”** when you are talking about a **completed action in the past**, often as part of a past event or when the time is known/understood.

 - **I did my homework yesterday.**
- **I watched that movie last night.**
- **I called Sarah this morning.**
- **I broke my phone.** → This can simply report a past event.

 The focus is on **the past action itself**.

 ### 2\. “I have done something” — Present Perfect

 Use **“I have done”** when the past action has a **connection to the present**. The exact time is usually not important or isn't mentioned.

 - **I have done my homework.** → It is finished **now**.
- **I have watched that movie.** → I have the experience of watching it.
- **I have called Sarah.** → The call has been made, and this is relevant **now**.
- **I have broken my phone.** → My phone is broken **now** as a result.

 The focus is on **the present result or experience**.

 ### Compare

 | Simple Past | Present Perfect |
| --- | --- |
| **I lost my keys yesterday.** | **I have lost my keys.** |
| Past event; yesterday is specified. | They are still lost / this matters now. |
| **I ate lunch at 1 PM.** | **I have eaten lunch.** |
| Tells us when it happened. | Says lunch is already done; time isn't important. |
| **She went to Paris in 2022.** | **She has been to Paris.** |
| Specific past event. | Life experience; no specific time. |

### A useful rule

 If you can naturally add a **finished past time**, use the simple past:

 > I **did** it **yesterday**.\
>  I **did** it **last week**.\
>  I **did** it **in 2020**.

 Don't normally use present perfect with a finished past time:

 > ❌ I **have done** it yesterday.\
>  ✅ I **did** it yesterday.

 But if the time period is **still continuing**, present perfect is possible:

 > **I have seen him twice this week.**

 Here, _this week_ isn't necessarily finished yet.

 ### One particularly important difference

 Imagine someone asks:

 > **“Why isn't the report ready?”**

 You could say:

 > **“I did the report.”** — You're simply reporting that you completed it in the past. The context may make the timing clear.

 > **“I have done the report.”** — You're emphasizing that **the report is now finished**, perhaps so the person knows they can use it.

 So, roughly:

 **I did it** → _past event_\
 **I have done it** → _past action + relevance/result now_
